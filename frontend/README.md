# TaskFlow — Frontend

React + TypeScript + Vite. TanStack Query, Zustand, Tailwind v4, @dnd-kit, react-hook-form + zod.

```bash
npm install
npm run dev              # http://localhost:3000 (проксі /api, /socket.io → :8080)
npm run build            # tsc -b && vite build
npm test                 # Vitest + React Testing Library
npm run storybook        # Storybook (UI-компоненти)
```

Повна документація проєкту — у [кореневому README](../README.md).
